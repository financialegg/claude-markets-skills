# גרפים פיננסיים בעברית

## עברית ב-matplotlib

matplotlib גרסה 3.11 ומעלה מציג עברית נכון כמות שהיא. **אל תשתמש ב-`python-bidi` או ב-`get_display`**: זה הופך את הטקסט פעמיים והוא יוצא הפוך. בגרסה ישנה יותר, בדוק קודם עם `python -c "import matplotlib; print(matplotlib.__version__)"`.

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.rcParams["font.family"] = "DejaVu Sans"   # כולל אותיות עבריות
fig, ax = plt.subplots(figsize=(6, 3.4), dpi=200)
ax.set_title("הכנסות (מיליארד $)", loc="right")
fig.text(0.99, 0.01, "מקור: דוחות החברה, 9.10.2026", ha="right", fontsize=7)
```

## כללים לכל גרף

1. **גרף אחד, מסר אחד.** הכותרת אומרת מה רואים, לא רק מה הציר ("ההכנסות ירדו ברבעון השלישי", ולא "הכנסות").
2. **משפט הסבר מתחת לגרף.** שלושה חלקים: מה רואים, מה זה אומר, ומה הכיוון (חיובי, שלילי או ניטרלי). הכיוון נכתב במילים ולא רק בצבע.
3. **מקור ותאריך** בתחתית הגרף, ויחידות (מיליארד דולר, אחוזים) על הציר.
4. **ציר הזמן משמאל לימין**, כמקובל בכלכלה. הטקסט והכותרות מיושרים לימין.
5. **עמודות מתחילות מאפס.** קו יכול להתחיל מכל ערך, אבל אם הציר חתוך, כתוב זאת.
6. **בלי תלת-ממד ובלי שני צירים בלי סימון ברור.** לא יותר משש סדרות בגרף אחד.
7. **צבעים עקביים** בכל הגרפים של אותו מסמך, ועם ניגודיות מספקת. אל תסתמך על אדום מול ירוק בלבד.

## בדיקה לפני שמגישים

פתח את קובץ התמונה ובדוק בעיניים: טקסט לא הפוך, תוויות לא חופפות, הכל נכנס בשוליים, והמספרים בגרף זהים לנתוני המקור. אל תכריז שהגרף תקין בלי שראית אותו.
