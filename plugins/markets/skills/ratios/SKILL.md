# ניתוח יחסים פיננסיים

חומר לימוד בלבד. עבוד גם לפי הסקיל `research-rules`.

## עקרונות

- אין יעד אחד נכון ליחס. השווה **להיסטוריה של החברה** (4 עד 8 רבעונים או 3 עד 5 שנים) ולחברות באותו ענף. המגמה חשובה יותר מנקודה אחת.
- כל יחס מוצג עם התקופה והנוסחה. אותו יחס, אותה הגדרה, בכל התקופות.
- בנקים, ביטוח ונדל"ן דורשים יחסים אחרים (הלימות הון, יחס משולב, FFO). אל תפעיל עליהם את הרשימה הכללית.

## היחסים

**נזילות:** יחס שוטף = נכסים שוטפים / התחייבויות שוטפות. יחס מהיר = (שוטפים פחות מלאי) / התחייבויות שוטפות.

**מינוף:** חוב נקי / EBITDA. כיסוי ריבית = EBIT / הוצאות ריבית. חוב להון = חוב / הון עצמי. כדאי לבדוק גם את לוח הסילוקין: כמה חוב נפרע בשנתיים הקרובות.

**רווחיות:** שולי רווח גולמי, תפעולי ונקי. ROE = רווח נקי / הון עצמי ממוצע. ROIC = NOPAT / (חוב + הון פחות מזומן), כאשר NOPAT = EBIT × (1 פחות שיעור מס).

**יעילות:** DSO = לקוחות / מכירות × ימי התקופה. DIO = מלאי / עלות המכר × ימי התקופה. DPO = ספקים / עלות המכר × ימי התקופה. מחזור מזומן = DSO + DIO פחות DPO.

**תזרים:** FCF = תזרים מפעילות פחות Capex. המרת תזרים = FCF / רווח נקי. שולי FCF = FCF / מכירות.

## פלט

1. טבלה: יחס, ערך נוכחי, ערך קודם, שינוי, הערה אחת.
2. שלוש הערות מרכזיות: מה השתפר, מה הידרדר, ומה דורש הסבר.
3. שאלות פתוחות לדוח הבא.

חישובים עם יותר משני שלבים נעשים בקוד או בגיליון. סיום: **היחסים מתארים את העבר ואינם תחזית.**
